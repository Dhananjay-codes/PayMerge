# PayMerge – Unified UPI Payment Management App

**PayMerge** is an Android application prototype designed to provide users with a single platform to access multiple UPI payment applications and maintain a centralized transaction history.

Instead of switching between different payment applications, users can select their preferred UPI app through PayMerge and keep a record of their transactions in one place.

## 🚀 Key Features

- **QR Code Scanning:** Scan a QR code to initiate a payment.
- **Amount Entry:** Enter the amount before proceeding with payment.
- **Multiple UPI Apps:** Choose from available UPI payment applications.
- **UPI Intent Integration:** Redirect users to their selected UPI application.
- **Transaction History:** Maintain a centralized record of transactions.
- **Transaction Status:** Record Success, Failed, Cancelled, and Pending statuses.
- **Simple UI:** Clean and user-friendly Android interface.

## 🛠️ Technology Stack

- **Language:** Kotlin
- **Platform:** Android
- **UI Framework:** Jetpack Compose
- **IDE:** Android Studio
- **Build System:** Gradle

## ⚙️ How It Works

1. Open the PayMerge application.
2. Scan a QR code or enter the payment amount.
3. Select an available UPI payment application.
4. PayMerge redirects the user to the selected UPI app using Android UPI Intent.
5. After returning to PayMerge, the transaction status can be recorded.
6. View transaction details in the centralized transaction history.

## 📱 Project Status

PayMerge is currently a prototype developed for learning and demonstration purposes.

**Note:** PayMerge does not directly process or transfer money. Actual payments are handled by the selected UPI application. If automatic transaction status verification is unavailable, the prototype allows the user to record the status manually.

## 🎯 Project Objective

The main objective of PayMerge is to simplify the management of UPI payment activities by providing a centralized interface for accessing payment applications and viewing transaction records.
